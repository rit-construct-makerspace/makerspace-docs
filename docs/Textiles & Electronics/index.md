### Free Electrical Components

In order to assist with projects, we try to stock a number of free basic electrical components for student use. **Please use these parts sparingly** so everyone has access to this resource! If you need more than a few, consider purchasing your own from a proper electronics supplier. We do not have an in-depth inventory, but generally we stock the following;

* Resistors and capacitors in standard increments in THT and SMD packages
* LEDs in multiple colors in THT and SMD packages
* Other passive electrical components like inductors, ferrite beads, chokes, etc.
* Transistors (BJT, Darlington, and MOSFET) in THT packages
* Other active silicon components like diodes, rectifiers, clamps, etc.
* Basic logic gates (74HC and 74LS series)
* Electromechanical components like switches, buttons, encoders, potentiometers, etc.
* Basic ICs like motor drivers, amplifier, regulators, etc.
* Wires, terminations, and plugs.
